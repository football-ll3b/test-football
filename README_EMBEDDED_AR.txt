1) فك ضغط ZIP وانسخ محتوياته إلى «على الـ iPad» إذا ظهرت مشاكل iCloud.

3) افتح index.html داخل مجلد الاختبار بعد تحديث GitHub Pages.
4) راجع الفئات والخزنة والصوت والحفظ على Safari قبل استبدال النسخة الشغالة.
